# Generated corpus and classifications

This directory contains record-level research derivatives. Five canonical files
are tracked so the campaign can be resumed; all transcripts, historical runs,
calibrations, reports, and logs remain ignored. The production pipeline creates
or expects:

- `long_conversations_10x10.jsonl.gz`: canonical expanded v5 corpus of 91,590
  exact-deduplicated normalized conversations, ignored;
- `long_conversations_manifest.json`: generated aggregate and expansion
  manifest, ignored;
- `gemma4_26b_a4b_audit_v5_extension_levels.jsonl`: tracked append-only
  automated audit;
- `gemma4_26b_a4b_audit_v5_extension_levels_errors.jsonl`: tracked retryable
  error ledger;
- `manually_reviewed_clear_examples.jsonl`: tracked;
- `manually_reviewed_potential_examples.jsonl`: tracked; and
- `manually_reviewed_none_examples.jsonl`: tracked.

The last three files are human adjudications and cannot be regenerated by the
automated classifier. Their record format and review procedure are documented
in `wiki/workflow/manual-review.md`.

Older local files in this directory are pilot, calibration, superseded
measurement, or historical review outputs. They must not be merged with v5 as
if they came from one instrument.
