# Generated corpus and classifications

This directory contains record-level research data and is ignored by Git. The
production pipeline creates or expects:

- `long_conversations_10x10.jsonl.gz`: normalized conversations;
- `long_conversations_manifest.json`: aggregate corpus manifest;
- `gemma4_26b_a4b_audit_v5_extension_levels.jsonl`: append-only automated
  audit;
- `gemma4_26b_a4b_audit_v5_extension_levels_errors.jsonl`: retryable errors;
- `manually_reviewed_clear_examples.jsonl`;
- `manually_reviewed_potential_examples.jsonl`; and
- `manually_reviewed_none_examples.jsonl`.

The last three files are human adjudications and cannot be regenerated by the
automated classifier. Their record format and review procedure are documented
in `wiki/workflow/manual-review.md`.

Older local files in this directory are pilot, calibration, superseded
measurement, or historical review outputs. They must not be merged with v5 as
if they came from one instrument.
